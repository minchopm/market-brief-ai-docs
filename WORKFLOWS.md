# Market Brief AI — practical workflows

These are suggested user procedures, not claims that automated tests have been performed. Each workflow has a concrete outcome to inspect.

## A reproducible historical study

Keep the asset, dates, data interval and model settings fixed for a baseline. Change one setting at a time and retain the earlier result. If you tune on a period, do not present that same period as independent validation.

## Read a decision log

Pick a marked event and inspect the available reason and prior bars. Distinguish information available at the time from later observations. Check whether costs and execution assumptions are represented before interpreting an equity curve.

## Evaluate an added context source

Compare the same setup with and without the source. Record missing data, publication time and update frequency. A visually plausible overlay is not proof of predictive value, and more inputs do not automatically make a model better.
